# Wireframes de ViandaSegura

Disenos de la segunda entrega, implementados en HTML y CSS (sin backend). Cada
carpeta tiene el boceto original (`wireframe-NN.jpeg`) y su version navegable
(`index.html`). Para verlos alcanza con abrir el `index.html` en el navegador.

> Los HTML ya usan el nombre **ViandaSegura** y la paleta azul marino. Los
> `.jpeg` son los bocetos originales y conservan el nombre y los colores anteriores.

La pantalla funcional que corresponde a cada wireframe esta descrita en la
[guia de pantallas](../sistema/docs/pantallas.md) y las diferencias entre diseno e
implementacion en [flujo de navegacion](../sistema/docs/flujo-navegacion.md#correspondencia-con-los-wireframes-de-la-segunda-entrega).
